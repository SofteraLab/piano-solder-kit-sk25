# Пайка

## Вивідні кнопки

![Пайка кнопок](./assets/images/uk/soldering-buttons.jpg)

- 8 кнопок — ноти **C–B–C**  
- 4 ніжки — не перегрівай  
- Вирівняй перед пайкою всіх ніжок  
- Перевір натискання — клацає  

## Діод D1

![Діод D1](./assets/images/uk/diode-d1.jpg)

Полярність: **смужка = катод**. Не переплутай.

## Динамік (опційно)

![Підключення динаміка](./assets/images/uk/speaker.jpg)

Зручніше через **jack 3,5 мм** і навушники — динамік не обов’язковий. Якщо підключаєте динамік:

- **Червоний → +**  
- **Чорний → −**  
- Перевір звук на **C–B–C**
