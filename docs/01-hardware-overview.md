# Огляд плати

**Набір PIANO** — навчальна плата Softera Lab: після пайки граєте ноти на восьми кнопках. Звук іде на **jack 3,5 мм** для навушників (динамік не обов’язковий) або на опційні площадки динаміка.

![Як працює PIANO](./assets/images/uk/how-it-works.png)

## Зони

| Зона | Вміст |
| --- | --- |
| Клавіші | 8 × THT · C D E F G A B C |
| Пасивні | R1–R11, C1, C2 · переважно **1206** |
| U1 | МК · **SOIC-8** |
| D1 | Захисний діод |
| USB | Живлення 5 В |
| Навушники | **Jack 3,5 мм** — зручно, можна без динаміка |
| Динамік (опційно) | Площадки **+** / **−** |
