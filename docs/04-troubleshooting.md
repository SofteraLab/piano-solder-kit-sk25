# Діагностика

| Симптом | Перевірка |
| --- | --- |
| Немає живлення | Кабель USB дає 5 В; пайка USB |
| Немає звуку | Спершу **навушники в jack 3,5 мм**; або полярність динаміка **+** / **−** |
| Одна клавіша мовчить | Пайка цієї кнопки; резистор у колі |
| Плата «мертва» після живлення | Орієнтація діода **D1** (смужка = катод) |
| Слабкий / дивний тон | Ключ SOIC-8; холодні стики на U1 |

У запиті вкажіть набір **PIANO**, що саме не працює, і фото обох сторін.
