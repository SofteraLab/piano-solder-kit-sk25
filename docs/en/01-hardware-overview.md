# Board overview

**PIANO Kit** is a Softera Lab practice board: after soldering you play tones on eight buttons. Sound goes to a **3.5 mm headphone jack** (no speaker needed) or optional speaker pads.

![How PIANO works](../assets/images/en/how-it-works.png)

## Zones

| Zone | Contents |
| --- | --- |
| Keys | 8 × THT buttons · C D E F G A B C |
| Passives | R1–R11, C1, C2 · mostly **1206** |
| U1 | MCU · **SOIC-8** |
| D1 | Protection diode |
| USB | Power input 5 V |
| Headphones | **3.5 mm jack** — convenient, works without a speaker |
| Speaker (optional) | Pads **+** / **−** |
