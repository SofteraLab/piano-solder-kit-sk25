# Troubleshooting

| Symptom | Check |
| --- | --- |
| No power | USB cable supplies 5 V; USB joints solid |
| No sound | Try **3.5 mm headphones** first; or speaker polarity **+** / **−** |
| One key silent | That button joints; R in that path |
| Board dead after power | Diode **D1** orientation (stripe = cathode) |
| Weak / wrong tone | SOIC-8 pin 1; cold joints on U1 |

When asking for help: kit **PIANO**, what fails, clear photos of both sides.
