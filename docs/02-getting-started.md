# Збірка

![Набір PIANO](./assets/images/uk/kit-intro.png)

## Рекомендований порядок

| Крок | Дія |
| --- | --- |
| 1 | SMD **1206** і діод **D1** |
| 2 | МК **SOIC-8** — ключ pin 1 |
| 3 | Роз’єм USB |
| 4 | THT-кнопки C–B–C |
| 5 | **Jack 3,5 мм** для навушників |
| 6 | За бажанням динамік **червоний → +**, **чорний → −** |
| 7 | USB → натиснути клавіші → перевірити звук (навушники або динамік) |

:::caution Діод D1
Смужка = катод. Неправильна орієнтація блокує плату.
:::
