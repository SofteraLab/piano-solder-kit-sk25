# Firmware

PIANO Kit uses an **SOIC-8** microcontroller that generates tones for the note buttons **C–B–C**.

Demo firmware plays notes when you press the keys. Audio goes to the **3.5 mm headphone jack** (works without a speaker) or optional speaker pads (**+** / **−**).

Firmware sources are Softera Lab IP and are **not** published here.
